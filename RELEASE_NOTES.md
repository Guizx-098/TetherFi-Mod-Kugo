## Kugo Hotspot 1.0.5

Baixe o arquivo `.apk` abaixo e instale no Android (permita fontes desconhecidas, se pedido).

### Importante
- Esta versão passa a usar uma **assinatura fixa**. Por isso, **desinstale a versão anterior uma única vez** antes de instalar esta (as configurações e apelidos serão perdidos). A partir daqui, as próximas versões instalam **por cima**, sem desinstalar.

### Novidades
- **Aviso de atualização:** ao abrir o app, ele verifica se há uma versão nova aqui no GitHub e pergunta se você quer baixar. Dá para baixar na hora, instalar depois ou deixar para mais tarde.
- **Verificar atualizações:** botão novo no topo da aba Configurações.
- **Diagnóstico do Shizuku:** novo botão **Copiar resultado**.
